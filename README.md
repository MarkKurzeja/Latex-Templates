# LaTeX Templates

A collection of personal LaTeX templates for various document types.

To install TeX on Linux:

```
sudo apt-get install texlive-full
```

On Windows, use [MiKTeX](https://miktex.org/download).

## Templates

### ClassicThesis (`template_ClassicThesisMarkKurzeja.tex`)
A Robert Bringhurst-inspired thesis/paper template using the `classicthesis` package. Features elegant typography with EB Garamond, custom proof environments (Lamport-style numbering), quick figure insertion macros, and code listing support. Best suited for academic papers, essays, and long-form documents.

### Three Column Dense Sheet (`template_ThreeColDenseSheet.tex`)
A landscape, three-column summary sheet for condensing information into a compact handout. Includes custom `topic` and `tellme` environments for structured notes, compact list environments, proof environments, and Harvard-crimson color scheme. Ideal for study sheets, quick references, and presentation prep.

### Critical Notes Remake (`template_CriticalNotesRemake.tex`)
A chapter-based note-taking template using the `report` class with fancy chapter headings. Provides `notepage`, `point`, and `quicklist` macros for structured note organization. Well-suited for reading notes, article reviews, and critical analysis.
